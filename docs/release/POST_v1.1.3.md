# 发布帖草稿（v1.1.3）

**标题**：把 QQ 接进 DSH：会挑着接话、会潜水、会发表情的 AI 群友（开源）

---

DSH 里跑着 agent，但消息只能从聊天窗口进。这个项目把它接进 QQ——好友和群里的消息会变成 agent 的用户输入，它的回复、提问、工具审批再发回 QQ。

**它不像「定时播报」，更像群里一个人**：

- **会挑着接话**：不是每条都回，看语境、看关系、看热闹程度决定接不接；
- **有活人节奏**：分几条发、会等对方补话、会发表情、冷场就潜水；
- **有记忆和人格**：自己的角色卡、群友印象、正在聊的话题，换会话也不丢；
- **能当助手**：私聊里可以整理文件、查资料、定时提醒。

**装法**：别自己敲命令。把下面这句丢给 DSH：

> 克隆 https://github.com/h-D-ACE/dsh-qq 到本地，按 README 把依赖装好，复制 config.example.json 为 config.json 并引导我填群号和 QQ 账号，然后启动控制中心。

缺 Node、缺 NapCat 它会直接问你要。装完控制台扫码登录 QQ 小号。

**要准备**：一个 QQ 小号、一台长期开着的电脑、DSH 桌面版。跑起来会花 token 钱，多少取决于群有多活跃、你让它走几步——命中率一般 97% 以上，大头是「步数 × 上下文」。

**已知限制**：依赖 NapCat 登录，属于第三方协议端，稳定性和风控不在我们控制范围；只在 Windows 上长期跑过，macOS/Linux 有 CI 但没长时间验证。
